# News

The news/blog features let your community publish articles. Enable them via
**Admin → Settings → General → Enable news features**.

- **Admin → News** is where moderators create, edit, publish and delete articles.
- Each article has a title, body, and a published state; published articles are shown on
  the site.
- Published articles are announced to a Discord channel (see
  [Discord Reference](discord.md)). The posted message is tracked, so editing the
  article updates the same Discord message in place instead of posting a
  duplicate, and deleting the article removes the message.
