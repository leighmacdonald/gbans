# Patreon

gbans integrates with [Patreon](https://www.patreon.com/) via OAuth. Enable it via
**Admin → Settings → Patreon → Enable Patreon Integration** and configure your Patreon API
credentials and campaign in the same tab.

- Supporters link their account from **Settings → Connections → Patreon** and can
  disconnect it there.
- Linked patrons are recognised on their profile.
- Patreon activity (e.g. new supporters) can be posted to a Discord log channel.
