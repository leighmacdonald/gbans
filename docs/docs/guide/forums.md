# Forums

The **Forums** (`/forums`) are a lightweight community forum, enabled via
**Admin → Settings → General → Enable forums**.

- **Categories** group **forums** (boards), which contain **threads**, each a sequence of
  **posts**.
- Players with the `forum_edit` permission can create and edit categories and threads, and
  moderate posts (delete, etc.).
- Signed-in players can browse, read and reply where their permissions allow.

New activity can be posted to Discord, and your [forum signature and profile-signing](settings.md#forums)
are configured in your settings.

:::note
The forums are still a work-in-progress area; some moderation flows may evolve.
:::
